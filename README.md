# Matt’s 3D Customs Inc.

Design Your Imagination. For the Future is Yours.

Static, responsive dark camo green (#2E4A3A) website, ready for **GitHub Pages** (Settings → Pages → deploy from branch, root).

Pages: `index.html`, `shop.html` (filters), `product.html?id=…`, `custom.html`, `about.html`, `contact.html`, `faq.html`.

## Setup
- Products live in `js/products.js`; images in `assets/products/`.
- Forms use Formspree: replace `YOUR_FORM_ID` in `custom.html` and `contact.html` (Netlify Forms attributes are also included).
- Replace placeholder email, phone, address and social links in `contact.html`, `product.js` and the footer.
- Payments are manual (Cash App, Venmo, Zelle, PayPal); there is no checkout.
